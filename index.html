Rejoindre en 3 étapes

Il te faut Minecraft Java Edition dans la version indiquée sur le serveur.

  1. Copie l’adresse
    Utilise le bouton « Copier » du serveur de ton choix.
  2. Ouvre le menu Multijoueur
    Puis clique sur « Ajouter un serveur ».
  3. Colle l’adresse et joue
    Valide avec « Terminé », puis double-clique sur le serveur.

Questions fréquentes

Quelle version de Minecraft faut-il ?

Minecraft Java Edition. La version exacte est affichée sur chaque serveur dans la liste ci-dessus.

Le serveur est hors ligne, que faire ?

Nos serveurs sont hébergés sur Aternos et s’éteignent quand personne n’est connecté. S’il est hors ligne, il faut attendre qu’un membre de l’équipe le démarre.

Est-ce gratuit ?

Oui, rejoindre les serveurs Build est gratuit. Il te faut seulement un compte Minecraft Java.

Quels modes de jeu proposez-vous ?

Des mini-jeux, du Bedwars et un serveur PvP Faction nommé Handaria.
