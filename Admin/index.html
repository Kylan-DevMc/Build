Boutique

Aternos interdit de gagner de l’argent réel avec un serveur : garde des prix en monnaie du jeu tant que tu es chez eux, et laisse le lien de paiement vide.
Connexion GitHub (une seule fois par appareil) Pour que les changements soient visibles par tous, le site écrit dans ton dépôt GitHub. Crée un token « fine-grained » limité à ce dépôt, avec la permission Contents : Read and write (voir le README). Il reste uniquement dans ce navigateur.
